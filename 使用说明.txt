A border Job 1.1.2 — 可本地运行、修改的独立实现

A border Job 为本地自定义品牌，功能参考原版 Ghost Job：https://github.com/InfernalAzazel/ghost-job；不是原版官方发行版。

打开软件（Windows 文件资源管理器）
1. 将 Windows 便携 ZIP 完整解压到自己选择的目录（例如 D:\GhostJob-Local），然后打开该文件夹。
2. 双击 Start.vbs：打开正式工作区，地址 http://127.0.0.1:17839。
3. 双击“模拟演练.vbs”：打开独立演练工作区，地址 http://127.0.0.1:17842。
4. 没出现窗口时，双击对应 .cmd 文件查看提示。
5. 关闭窗口后服务仍在后台；完全退出请双击 Stop.cmd。

模拟一遍（无需粘贴命令、无需登录、无需 AI Key）
1. 在“模拟演练环境”窗口点击“运行完整演练”。
   成功后显示 6 个通过步骤，虚构岗位、会话、企业报告和统计已生成。
2. 点“岗位管理”：可看到 3 个已沟通岗位；低分、低活跃度岗位被跳过。
   点击“高匹配”查看评分 >=80 的岗位，点击“详情”或“企业查询”查看资料。
3. 点“消息”：查看 6 个虚构 HR 会话。
   林 HR：模拟附件请求已处理；赵/李 HR：已发送模拟回复。
   周 HR：岗位不匹配，礼貌婉拒；陈 HR：面试安排保留草稿；黄 HR：拒绝后不再回复。
   状态下拉框可标记“已面试 / 面试通过 / 面试不通过”。再次同步不会覆盖这些状态。
4. 点“求职分析”：查看冻结快照、成功次数/样本数、95% 可信区间与分组统计。
   可以重新生成 AI 解读、下载 PDF、创建或删除报告。
5. 点“配置中心”：查看完整筛选、节奏、简历、AI 与回复设置。
   普通单项修改离开输入框后自动保存；自动发送和 API Key 需点击“保存配置”。
6. 再次演练不会重复投递已有岗位。需要重新体验初始状态时，先 Stop.cmd，
   将 data-simulation 重命名为 data-simulation-backup，再打开模拟演练。

正式使用
1. 求职配置：填写岗位关键词、城市，多个值用逗号分隔，按顺序搜索。
   支持类型、薪资、经验、学历、融资、规模、行业、标题包含/排除、公司白名单/黑名单。
   缺失的网页字段按未知处理，不当作不匹配。行业等字段以页面可读信息为准。
2. AI 服务：填写兼容 Chat Completions 的地址、API Key、模型；测试连接并保存。
   支持 DeepSeek、通义千问、Kimi、智谱、OpenAI 和本地 Ollama 的兼容接口。
3. 简历配置：导入文字型 PDF/TXT/Markdown，或粘贴文字。扫描件需要先识别文字。
4. 方向筛选、简历匹配、分数过滤可分别开启；活跃度先于 AI 判断，减少不必要调用。
5. 工作台打开求职浏览器，用户自行登录 BOSS。默认自动发送关闭。
   可先手动搜索并“读取当前页”，再分析；开启自动沟通后开始任务才会操作真实岗位。
6. 历史同步会逐个读会话并关联岗位；可停止续传。全量同步与投递/回复互斥。
   投递与回复使用各自标签页。网站登录、验证码和验证弹窗需本人处理。
7. 自动回复可以覆盖所有可读取会话或当前会话，按北京时间工作时段与停顿设置执行。
   面试时间、薪资、到岗、身份信息等留待人工确认，不擅自承诺。
8. 附件：使用已经上传到 BOSS 的简历。HR 请求卡可“同意”，否则发出简历请求。
   确认状态不明时停在“待核实”，不会重复尝试；可到 BOSS 手动确认。
9. 企业查询：读取公司页面、按企业名称检索公开线索，可选 AI 解释，缓存并复用结果。
   无 AI Key 时仍可查看原始资料/线索，风险显示“信息不足”；未搜到负面不等于没有风险。
10. 求职分析：本机统计，不需要 AI Key；生成时冻结数据，之后可单独请求/重试 AI 解读。
    Beta(1,1) 后验均值与95%可信区间；无聊天记录的投递不算回应率分母。
    仅明确由自动任务发送且成功确认的回复计入自动回复样本；人工确认发送的 AI 草稿不计入。
    匹配分不是录用概率，分组差异不能证明策略因果。

数据、备份与修改
data：正式工作区；data-simulation：模拟工作区；彼此隔离。
ghost-job.sqlite：本地业务数据；local.key：API Key 本地加密密钥。
boss-profile：专用浏览器登录资料；app-profile：应用窗口资料。
JSON 导出/导入支持岗位、会话、消息、企业报告和统计快照，不含密钥或登录资料。
完整备份：停止服务后复制整个 data 文件夹（含 local.key），妥善保存。
代码是本地可编辑文件：public 界面，lib/browser.mjs 网页适配，lib/workflows.mjs 业务流程，
lib/store.mjs 数据，lib/analytics.mjs 统计，lib/ai.mjs 模型接口，server.mjs 本地服务。
运行：Node.js 24+；本机安装目录 runtime 已包含 Node，无需 npm 安装。
Windows 便携版自带 Python 用于 PDF 提取；PDF 导出由应用直接生成。源码版可自行安装 Python。
测试：node --test tests/*.test.mjs。

1.1.1 稳定性修复
— 当前网页会话身份无法核实时停止同步和发送，不沿用旧会话。
— 停止自动回复会取消尚未发起的发送；已提交给网页的操作无法撤回，状态未确认时保留待核实。
— 附件必须出现本人附件卡片及成功回执；普通简历文字不再算成功。
— 待分析、分析失败和未沟通岗位可继续处理；已沟通及待核实岗位保留去重。
— 连续配置修改合并保存，切换配置页等待保存完成，失败可重试。
— 自动回复统计仅计算确认自动发送；消息增量同步保留完整顺序。
— 粘贴消息立即更新并选中对应会话。
— 旧统计快照保持冻结，如需修复后的统计口径，请新建快照。

测试范围：本地接口、业务模拟、DOM 固定样本和本地界面。不代表当前真实 BOSS 网页所有布局均兼容。


1.1.2 便携发布
Windows x64 发布包自带官方 Node.js 24.22.2 和 Python 3.14.10，不需要安装 Codex 或 npm 依赖。
请完整解压，不要直接在 ZIP 里双击运行。使用 Google Chrome 作为应用窗口和求职浏览器。
程序首次启动会创建新的空白工作区。简历、API Key、账号登录和聊天数据均未包含在发布包。
